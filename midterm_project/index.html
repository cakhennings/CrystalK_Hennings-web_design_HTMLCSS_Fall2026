Welcome to the Home Page

This page offers an overview of the web design projects completed over the first 8 weeks of the Fall 2026 Semester Web Design, HTML, CSS course. Learnings include semantic HTML to understand the rules for creating and organizing the structure of a webpage as well as Cascading Style Sheets, CSS, to transform the look of a website into a visually appealing and responsive tool for communicating with external entities. The earliest projects provided opportunities to learn and practice creating a webpage using semantic HTML and CSS reset. Later projects include basic CSS to add color and visual appeal to web design projects. The very latest projects in the portfolio include emphasis on responsive web design and incorporate media queries, custom css variables, and a mobile first web design approach.
